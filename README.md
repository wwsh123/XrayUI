# XrayUI-Portable

一个为 Windows 设计的便携式代理客户端，目标是把“开箱即用、轻量、稳定、多节点分流、无缝迁移”这几件事做到极致。

> 本项目基于 [vimbackground/XrayUI](https://github.com/vimbackground/XrayUI) 继续演进，并在便携性、分流能力、启动稳定性和 Native AOT 发布体验方面做了更适合本地使用场景的增强。项目名称、发布包和功能演进均与上游仓库区分管理，不代表上游项目官方发行版。

## 项目简介

XrayUI-Portable 采用 WinUI 3 + Xray 核心，提供：

- 全绿色便携运行：无需安装，配置与订阅保存在程序目录下的 `Data/` 中
- 多节点并行分流：一个客户端同时管理多个代理节点，并为不同节点分配独立本地监听端口
- 稳定的端口冲突处理：自动检测占用、推荐空闲端口、恢复重试
- 低资源占用：Native AOT 发布，启动快、体积小、内存占用低
- 运行状态可视化：实时日志、流量统计、节点状态、主/辅代理分离控制
- 灵活扩展：支持常见协议、TUN 模式、智能分流、AI 解锁检测等能力

## 1.2.3 版本亮点

本版本聚焦于对比上游的使用体验提升与稳定性优化，重点包括：

- **端口恢复行为更稳**：修正切换主节点或重启代理后出现的端口冲突误判与恢复异常，减少旧连接残留造成的误弹窗；
- **全局代理默认关闭**：默认关闭全局代理状态，减少误用场景，提升启动和切换的稳定性；
- **增补流量统计功能**：同时支持总流量统计与实时网速显示，便于观察代理实际带宽和累计使用情况；
- **多网卡分流功能增加**：支持按网卡指定分流，不同节点可绑定到不同网络出口；
- **AI 检测功能提升**：不仅支持延迟检测，还增加 Gemini 检测，并支持检测失败时自动切换到下一个可用节点；
- **增补窗口和按钮**：优化界面交互，补充更直观的操作入口和状态窗口，降低使用门槛。

## 功能亮点

### 1. 真正的全绿色免安装

- 所有订阅、节点、规则、日志和缓存均保存在程序同级目录下的 `Data/` 文件夹中
- 可直接复制整个目录到新电脑、U 盘或其他 Windows 设备中使用
- 软件启动不依赖安装过程，也不需要重新导入配置

### 2. 多节点分流模式

- 可以同时连接多个节点，不必反复切换国家/地区
- 为每个节点分配独立或可选的本地监听端口
- 其他软件只需使用指定端口即可按需分流上网
- 适合同时处理网页、视频、游戏、办公等不同场景

### 3. 智能端口处理与自动修复

- 启动前会检查端口占用情况，避免常见冲突导致无法运行
- 当端口被其他软件占用时，会自动推荐空闲端口并提示一键切换
- 关闭或切换主节点后，旧连接会优先清理残留监听，减少“卡住、无法重连”的情况

### 4. 原生 Windows 体验

- 使用 WinUI 3 原生界面，兼容 Windows 10 / 11
- 支持深浅色主题与云母/亚克力半透明效果
- 以 Native AOT 方式发布，程序启动更快，资源占用更低

### 5. 全局快捷键与运行监控

- 支持一键隐藏/显示窗口、开关代理、切换全局/分流模式
- 可查看主代理与辅助代理的运行状态、日志和流量
- 可单独关闭特定代理节点，不需要回到主界面反复操作

### 6. 协议与网络能力

支持主流代理协议，包括：

- VLESS
- VMess
- Trojan
- Shadowsocks
- Hysteria2
- WireGuard
- Proxy Chain / 链式代理

另外支持：

- 智能分流
- TUN 虚拟网卡模式
- AI 常用服务解锁检测
- 自动在可用节点间尝试恢复连接

## 快速开始

1. 下载对应版本的发布包
2. 解压到任意目录
3. 双击运行 `XrayUI-Portable.exe`
4. 如需保留配置、节点和订阅，请保持 `Data/` 文件夹与程序目录一起保留

> 重要：请不要把 `Data/` 文件夹单独删除或迁移到错误位置，否则配置和节点会失效。

## 常见问题

### Q1：如何开启多节点分流模式？

1. 打开软件设置（齿轮图标）
2. 找到“多节点分流模式”并开启
3. 返回主界面，选择需要单独监听端口的节点
4. 右键或使用菜单设置独立端口
5. 其他软件配合该端口即可实现按节点分流上网

### Q2：如何迁移到新电脑？

直接复制整个程序目录，包括 `Data/` 文件夹即可；无需重新导入订阅，原有节点和设置会保留。

### Q3：启动时报端口冲突怎么办？

软件会自动检测端口占用，并提供可用端口建议。确认后即可一键切换并继续运行。

### Q4：AI 解锁检测失败会怎样？

当当前主节点受限时，软件会尝试按节点列表顺序切换到下一个节点继续检测。若全部节点都不可用，请手动切换节点。

### Q5：如何单独关闭某个代理？

打开“代理动态信息”窗口，在查看列表中选择主代理或辅助代理，然后点击“关闭当前代理”。

